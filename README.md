# ChopTheBill

A web app for tracking and managing shared expenses across groups. Focus: tracking balances only (no payment integration).

## Tech Stack
- Frontend: React
- Backend: FastAPI
- Database: SQLite
- Deployment: Web application

## MVP Features
1. Add & track expenses with descriptions, payer, amount, and custom splits (unequal shares supported)
2. Automatic balance calculation with minimized transactions
3. Group management for friends, roommates, trips
